# Как выложить планер на GitHub Pages и поставить на телефон

Сайт живёт по адресу **https://fatoom333.github.io/day-planer/** и собирается прямо из ветки `main`, из корня репозитория. Сборки нет: GitHub отдаёт файлы как есть.

## 1. Слить изменения в `main`

Код лежит в ветке `claude/day-planer-v1-build-8gp132`. Pages смотрит на `main`, поэтому сначала ветку надо влить:

1. Открой https://github.com/fatoom333/day-planer.
2. Вверху появится жёлтая плашка «claude/day-planer-v1-build-8gp132 had recent pushes». Нажми **Compare & pull request**. Если плашки нет: вкладка **Pull requests** → **New pull request** → слева `base: main`, справа `compare: claude/day-planer-v1-build-8gp132`.
3. **Create pull request** → **Merge pull request** → **Confirm merge**.

## 2. Включить Pages (один раз)

1. В репозитории: **Settings** → слева **Pages**.
2. **Source**: `Deploy from a branch`.
3. **Branch**: `main`, папка `/ (root)` → **Save**.
4. Подожди 1–2 минуты. На вкладке **Actions** появится задача «pages build and deployment». Когда она станет зелёной, открой https://fatoom333.github.io/day-planer/.

Если видишь 404, подожди ещё минуту и обнови страницу: первая публикация бывает медленной.

## 3. Поставить на телефон (Chrome, Android)

1. Открой адрес в Chrome.
2. Меню **⋮** → **Установить приложение** (в некоторых версиях — **Добавить на главный экран** → **Установить**).
3. Запусти приложение с иконки: оно откроется без адресной строки.
4. Проверь офлайн: включи режим полёта и открой приложение. Экраны и задачи должны быть на месте.
5. В **Настройках** внизу есть строка о хранилище. После установки там обычно написано «Хранилище защищено». Если нет, почаще делай экспорт.

## Обновления

Каждый merge в `main` публикуется сам через 1–2 минуты. Телефон берёт файлы из офлайн-кэша, поэтому новая версия подхватится при запуске с сетью. Иногда приложение нужно закрыть и открыть ещё раз.

Для разработчика: при любом изменении файлов подними `VERSION` в `sw.js`, иначе телефон останется на старом кэше.

## Если что-то пошло не так

- **Пустой белый экран.** Скорее всего, в `main` попали не все файлы. Сравни список `FILES` в `sw.js` с репозиторием.
- **Старая версия не уходит.** Chrome → **⋮** → **Настройки** → **Настройки сайтов** → **Все сайты** → `fatoom333.github.io` → **Удалить данные**. Внимание: это сотрёт и задачи. Сначала сделай экспорт.
