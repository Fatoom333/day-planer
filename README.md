# day-planer

Динамический планер на день и неделю: PWA для телефона, пересчитывает расписание после каждого события и учится на расхождении между планом и фактом. Пары берутся из Google Calendar.

- Начато: 2026-09-25
- Статус: v1 собрана, security-проход пройден; для календаря нужен Client ID ([docs/google-setup.md](docs/google-setup.md))
- Выкладка и установка: [docs/deploy.md](docs/deploy.md)
- Тесты: `npm test` (Node 22+, без зависимостей)
